# Five-minute quick start

## Orientation

You will create a console app, install Humanizer `3.0.10`, and produce one deterministic duration. Use a .NET SDK that can create a project compatible with the selected package assets.

## Example

Create the project and add the selected package:

```console
dotnet new console --name HumanizerQuickStart
cd HumanizerQuickStart
dotnet add package Humanizer --version 3.0.10
```

Replace `Program.cs` with the verified source:

<CodeBlock language="csharp" title="Program.cs">{quickStart}</CodeBlock>

Run it:

```console
dotnet run
```

## Result

The program prints exactly:

```text
2 minutes
```

The assertion fails immediately if Humanizer `3.0.10` produces a different value.

## Pitfall

Many Humanizer operations use the current culture or UI culture when no culture is supplied. Set both explicitly in examples, tests, background work, and any operation whose output must be predictable.

## Version notes

This source is compiled and run against the selected Humanizer `3.0.10` package during documentation validation.
