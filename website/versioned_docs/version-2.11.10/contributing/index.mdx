# Contribute to Humanizer

## Orientation

This historical snapshot documents the published package, not the current
locale YAML or source-generator implementation.

## Example

```text
version + culture + input + expected output + actual output
```

Include that evidence in a language report.

## Pitfall

Do not apply current contributor internals to an older tag. Check out the exact
tag when maintaining its source.

## Version notes

Current locale-authoring and validation guidance is intentionally main-only.
