# Report a language issue

## Orientation

Report the selected Humanizer version, culture, runtime, input, expected
output, and actual output.

## Example

```text
Humanizer: selected snapshot
Culture: fr-FR
Input: ...
Expected: ...
Actual: ...
```

## Pitfall

Platform globalization data can differ. Include the operating system and
runtime instead of assuming the package alone produced the difference.

## Version notes

Historical packages predate the current locale YAML and source-generator
workflow. Use tagged source when proposing a historical correction.
