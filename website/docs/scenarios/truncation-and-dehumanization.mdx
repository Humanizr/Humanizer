# Truncation and dehumanization

## Orientation

Use `Truncate` to fit display text into a length or word budget. Use string `Dehumanize` to convert readable words to PascalCase when you control the vocabulary and only need an identifier-shaped value.

## Example

The default truncator uses the single-character ellipsis `…`. The same source
also verifies `Truncator.FixedNumberOfWords`; other built-in strategies can
count characters, preserve whole words, or truncate from the left.

## Pitfall

The meaning of `length` depends on the selected `ITruncator`, and the truncation marker consumes space for fixed-length strategies. `Dehumanize` is not a lossless inverse: punctuation and word boundaries can be discarded.

## Version notes

The verified source runs against `3.0.10` and current. Consult the selected-version API for the available `Truncator` strategies and overload order before changing an existing call.
