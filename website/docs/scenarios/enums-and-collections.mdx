# Enums and collections

## Orientation

Enum humanization turns member names into readable labels and honors metadata such as `DescriptionAttribute` and `DisplayAttribute`. Enum dehumanization maps those labels back to a member. Collection humanization joins rendered items with the conjunction and punctuation selected for the current UI culture.

Pass a separator when you need a particular conjunction, but remember that the
collection formatter controls its placement and punctuation.

## Pitfall

Enum dehumanization throws when no member matches unless you pass `OnNoMatch.ReturnsNull`. It is case-insensitive, but labels still need to be unambiguous.

Collection output is culture-specific. Set `CurrentUICulture` before calling `Humanize`, especially in tests and background work.

## Version notes

The verified enum and collection source runs against `3.0.10` and current. The exact built-in collection punctuation is locale data and may differ by selected release.
