# Strings and casing

## Orientation

Use `Humanize` to turn identifiers and delimiter-separated strings into display text. Pass `LetterCasing` when the destination requires sentence, title, lower, or upper casing. Use `Transform` when casing is the task by itself or when composing multiple transformers.

## Example

This verified source covers identifier humanization, casing, the reverse string operation, truncation, and a transformer:

`Humanize` recognizes PascalCase, camelCase, underscores, dashes, numbers, and common acronym boundaries. All-capital input is treated as an acronym and can remain unchanged; use a casing transformer when you intend to recase it.

## Pitfall

Title and sentence casing use culture-sensitive text operations. Set the culture explicitly when output must be deterministic, and do not assume title casing follows a particular editorial style guide.

## Version notes

The example runs unchanged against `3.0.10` and the current checkout. Unicode and punctuation edge cases have changed across releases; validate those inputs against the version your application uses.
